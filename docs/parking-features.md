# Operational features
Research: Parkable https://parkable.com/us emphasizes occupancy visibility. Get My Parking https://www.getmyparking.com/src/flyer/GMP-IQ.pdf emphasizes reports.
Implemented: current overall and per-zone occupancy, searchable vehicle register, All/Parked/Queued/Exited filters, eight-row pagination, direct checkout, CSV export of all matching records (not only the visible page), retained exited visits. Queue now shows all requests in a scrollable panel.
All values derive from local workspace records, not sensors. CSV files contain plates and should be handled as operational records. Timing/revenue analytics are not reported because the current model uses logical time units.
